Copy `.env.example` to `.env` next to `docker-compose.yml` and fill in `MONGO_URI`, `JWT_PRIVATE_KEY_B64`/`JWT_PUBLIC_KEY_B64` (generated via `cd backend && npm run generate:keys`), `OTP_PEPPER`, provider credentials, and `APP_BASE_URL`; replace `YOUR_DOMAIN` in `nginx/site.conf` with the production domain; ensure the external Docker volume `certbot-certs` exists before starting so Nginx can mount Let's Encrypt fullchain/privkey files.
